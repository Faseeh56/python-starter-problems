# 🐍 Python Starter Problems

> A hands-on Python practice repository built as part of my journey toward **AI Engineering**.

This repository contains my solutions to beginner-friendly Python programming problems designed around the fundamentals covered in **Python Class 2**.

The goal was not simply to memorize Python syntax, but to practice the basic programming cycle:

**Input → Store → Process → Decide → Output**

---

## 🎯 Purpose

This repository is part of my **AI Engineering from Scratch** learning journey.

Before working with NumPy, Pandas, Machine Learning, Deep Learning, and Generative AI, I am building a strong programming foundation with Python.

These programs focus on developing the ability to:

* understand a problem
* identify required inputs
* store information using variables
* process data using operators
* make decisions using conditions
* produce meaningful output
* test programs with different inputs

> **The objective is not to write more code. It is to understand the code we write.**

# 🧩 Programs

## 1. Personal Information

**File:** `01_personal_info.py`

A simple introduction to variables and output.

The program stores and displays personal information such as:

* Name
* Age
* University
* Degree
* Semester
* Favorite programming language

**Concepts:** `print()` • variables • strings • integers

---

## 2. Simple Calculator

**File:** `02_calculator.py`

A basic calculator that takes two numbers and performs arithmetic operations.

**Operations:**

* Addition
* Subtraction
* Multiplication
* Division
* Remainder
* Power

**Concepts:** `input()` • `int()` / `float()` • arithmetic operators • variables

---

## 3. Student Marks Calculator

**File:** `03_marks_calculator.py`

The user enters marks for multiple subjects, and the program calculates:

* Total marks
* Average marks

**Concepts:** input • numeric conversion • arithmetic • variables • data processing

---

## 4. Age Category Checker

**File:** `04_age_checker.py`

The program takes a user's age and categorizes them as:

* Child
* Teenager
* Adult
* Senior

**Concepts:** `if` • `elif` • `else` • comparison operators

---

## 5. Even/Odd + Positivity Checker

**File:** `05_even_odd.py`

The program analyzes an integer and determines:

* Whether it is positive, negative, or zero
* Whether it is even or odd

**Concepts:** `if / else` • comparisons • `%` operator • logical thinking

---

## 6. Shopping Discount Calculator

**File:** `06_discount_calculator.py`

A simple shopping system that calculates discounts based on purchase amount.

The program determines:

* Original amount
* Discount percentage
* Discount amount
* Final amount

**Concepts:** input • arithmetic • conditions • comparisons • decision making

---

## 7. Student Eligibility Checker

**File:** `07_student_eligibility.py`

A student is evaluated for eligibility for an AI Engineering training program based on:

* Age
* Semester
* CGPA

The decision uses multiple conditions together.

**Concepts:** variables • input • `int()` / `float()` • comparisons • `if / else` • `and`

---

## 8. Mini Project — Personal Profile Analyzer

**File:** `08_mini_profile_checker.py`

The final program combines the concepts from the previous exercises into one small interactive system.

The user provides information such as:

* Name
* Age
* University
* Semester
* CGPA

The program then:

* displays the profile
* determines age status
* evaluates academic status
* checks eligibility for the AI Engineering program

**Concepts combined:**

```text
Variables
   ↓
Input
   ↓
Data Types
   ↓
Arithmetic / Comparison
   ↓
Conditions
   ↓
Logical Operators
   ↓
Output
```

This serves as the **capstone exercise for the class**.

# 🚀 How to Run

Make sure Python 3 is installed.

Clone the repository:

```bash
git clone https://github.com/Faseeh56/python-starter-problems.git
```

Move into the repository:

```bash
cd python-starter-problems
```

Run any program:

```bash
python Programs/01_personal_info.py
```

For example:

```bash
python Programs/08_mini_profile_checker.py
```

Follow the prompts in the terminal.
